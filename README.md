
# 📖 芸窗朔梅 · AI 精准学习助手

> 一个纯前端、开箱即用的 AI 学习工作站 —— 把学习、思考、记录、复习全部揉在一起，在一个页面里完成从“我不会”到“我懂了”的全过程。

[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](http://makeapullrequest.com)

## ✨ 特性

- **🧠 学习四件套**：规划 → 讲解 → 刷题 → 费曼检验，一条龙学到底，主题自动传递
- **📚 全能阅读器**：支持 md / txt / pdf / docx / 图片，带标注、划词工具栏、AI 大纲、朗读
- **📝 心流笔记**：带标记的树状笔记法，AI 转写 + 笔记推理，结构化整理思路
- **💬 辅助对话**：角色扮演 + 记忆关联 + 联网搜索 + 主动提醒，打造专属私人助教
- **🗃️ 记忆库**：所有笔记的大本营，心流/札记/对话/翻译自动沉淀，双向关联
- **📖 摘抄本**：文字片段收集器，支持搜索替换、阅读设置
- **🌐 解语**：多翻译体系统，翻译 + 重点分析 + 古籍解语
- **⭐ 北辰**：书签收藏夹，支持导入/导出 HTML 书签
- **🎨 10 套中国风主题**：素雪、宣纸、碧落、青霜、苔青……自由切换
- **💾 数据完全本地化**：localStorage + IndexedDB，支持一键备份/恢复

## 🚀 快速开始

### 在线使用（推荐）

直接打开：[https://adikate-Alves.github.io/yunchuang-shuomei/](https://adikate-Alves.github.io/yunchuang-shuomei/)

> 纯 HTML，无需安装任何环境，打开即用。

### 本地运行

```bash
git clone https://github.com/adikate-Alves/yunchuang-shuomei.git
cd yunchuang-shuomei
# 直接用浏览器打开 index.html 即可
```

### 第一次使用

1. 打开左侧栏的 **API 配置**，填入你的 API Key（支持 DeepSeek、智谱 GLM、Minimax、OpenAI 等）
2. 选择你喜欢的**主题样式**
3. 开始学习！

## 🧩 功能模块速览

| 模块 | 说明 |
|------|------|
| **左栏** | 时钟 + 番茄钟计时器 + 全局设置（主题/API/存储/备份） |
| **中栏 - 学习** | 规划 / 通俗讲解 / 私教刷题 / 费曼检验，四步闭环 |
| **中栏 - 摘抄** | 文字片段收集，支持搜索/替换/置顶 |
| **中栏 - 心流** | 带标记的树状笔记，AI 转写 + 推理，一键同步记忆库 |
| **中栏 - 阅读** | 多格式阅读器，标注/划词/朗读/AI 大纲 |
| **右栏 - 辅助对话** | 角色扮演 + 记忆关联 + 联网搜索 + 主动提醒 |
| **右栏 - 札记** | 所见即所得 Markdown 编辑器，自动归入记忆库 |
| **右栏 - 记忆库** | 所有笔记汇总，按来源分组，支持搜索/筛选/导出 |
| **右栏 - 解语** | 翻译 + 重点分析，结果可存记忆库或送心流 |
| **右栏 - 北辰** | 书签收藏夹，支持导入/导出 HTML |

## 🔗 模块联动

所有模块不是孤立的，而是互相配合形成一个完整的学习闭环：

- 学习四件套：**规划 → 讲解 → 刷题 → 费曼**，主题自动传递
- **辅助对话** ⇄ **记忆库**：对话能查记忆，记忆能存对话
- **心流笔记** ⇄ **记忆库**：一键同步，双向关联
- **阅读器** ⇄ **札记** ⇄ **记忆库**：看书时随手记，自动沉淀
- **解语** → **记忆库 / 心流**：翻译结果可存记忆，也可送心流转译

## 🛠️ 技术栈

- 纯原生 HTML / CSS / JavaScript
- IndexedDB + localStorage（本地存储）
- 支持对接：DeepSeek、智谱 GLM、Minimax、OpenAI 等 API
- 流式输出 / 非流式输出 / 聊天输出（Waifu 模式）
